# 🔐 Federated & Privacy-Preserving AI

Research hub for **federated learning, privacy-aware machine learning and explainable collaborative AI**, maintained as part of Dr. Fahmid Al Farid's academic GitHub portfolio.

## Focus
- Federated learning
- Privacy-preserving AI
- Federated medical intelligence
- FL + explainable AI
- Distributed and collaborative learning
- Robustness and generalisation across clients/cohorts
